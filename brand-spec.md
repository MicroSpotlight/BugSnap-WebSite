## Visual system

### Color palette

- Primary action: `#1689F8`
- Primary hover: `#006BD6`
- Canvas: `#F4F5FA`
- Surface: `#FFFFFF`
- Brand surface / ink: `#15171D`
- Muted ink: `#656A75`
- Functional green: `#29D454`
- Annotation orange: `#FF9F0A`

### Typography and geometry

- Display and body: San Francisco semantic system stack
- Data and labels: SF Mono semantic stack
- Type scale: 13 / 16 / 20 / 32 / 56 / 80
- Spacing: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 80 / 120
- Surfaces: 12 / 20 / 32 px radii; one light shadow depth
- Touch targets: at least 44 px

### Vibe keywords

- native
- practical
- trustworthy
- developer-focused
- evidence-first

## Completeness notes

- Real product assets are available, so the site uses no substitute UI imagery or invented product renders.
- The App Store release is still in preparation; the site does not claim public availability or invent a download URL.
